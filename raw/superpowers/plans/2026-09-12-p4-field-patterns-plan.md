## T1 — Friction: Stop-gate trigger (d)

Files: `templates/core/scripts/hooks/strata_stop_gate.sh` (+ mirror to `scripts/hooks/`),
`scripts/test_p4_friction.sh` (new), `scripts/validate.sh` §12, `templates/core/
claude-settings-hook.json` note, `wiki/entities/stop-gate.md`, `CLAUDE.md` status row.

1. **Tests first** — `scripts/test_p4_friction.sh`, same fixture discipline as `test_p2_state.sh`
   (throwaway repo, real scripts, pinned `main`). Synthetic transcripts are generated by a helper
   (`mk_transcript <path> <interrupts> <denials> <errors> [sidechain]`). Cases: clean → silent;
   2 interrupts → block, reason carries `2 interrupt`; second Stop same session → silent (cap);
   1 denial → silent, 2 → block; 8 errors → block, `STRATA_FRICTION_ERRORS=0` → silent; all
   thresholds 0 → silent; `transcript_path` missing or unreadable → silent (fail open); friction +
   a `wiki/log.md` line appended after the stamp → silent; friction + branch state touched after
   the stamp → silent; friction + trigger (b) also due → one block whose reason has both; interrupts
   only on `"isSidechain":true` lines → silent; a project with neither `wiki/log.md` nor a branch
   state → silent; timing: a 5 MB clean transcript adds < 150 ms to the gate (best of 7, printed).
   `verify`: `bash scripts/test_p4_friction.sh` — red on the untouched gate.
2. **Gate** — parse `transcript_path` like `session_id`; one `awk` pass with the sidechain filter:
   interrupts = `"type":"user"` lines containing `[Request interrupted by user`; denials = lines
   matching `STRATA_FRICTION_DENY_RE` (default `doesn't want to proceed`); errors =
   `"is_error":true` lines that are not denials. Thresholds `STRATA_FRICTION_INTERRUPTS=1`,
   `STRATA_FRICTION_DENIALS=2`, `STRATA_FRICTION_ERRORS=8`; `0` disables a signal. Trigger (d)
   fires only when (a)–(c) did not, some signal meets its threshold, somewhere to record exists
   (`wiki/log.md` or a branch state), and nothing was recorded since the stamp (log line count
   unchanged, state file not `-newer` than the stamp). Reason: counts + the one-line instruction.
   When (a)–(c) fired and friction is present, append the counts to that reason. Run the pass last.
   `touch .strata/guard-tests` before the first edit; `rm -f` once green.
   `verify`: `bash scripts/test_p4_friction.sh` green; `bash scripts/test_p1_gates.sh`,
   `test_p2_state.sh`, `test_p3_guards.sh` still green; `cmp` template vs `scripts/hooks/` copy.
3. **Wire + document** — `validate.sh` §12 runs the new test; `_strata_note` mentions trigger (d);
   `wiki/entities/stop-gate.md` lists (d); `CLAUDE.md` status table gains the row.
   `verify`: `bash scripts/validate.sh` green through §12.
